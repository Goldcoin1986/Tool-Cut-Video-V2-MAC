# resemblyzer loads its bundled pretrained model weights via
# pkg_resources (part of setuptools) at runtime. This is a TWO-part
# problem, both parts need this one pin:
#   1. Python 3.12+ no longer auto-installs setuptools into every new
#      environment the way older Python versions did, so it can be
#      completely absent on a fresh install.
#   2. Even if setuptools IS installed, setuptools 82.0 (Feb 2026)
#      went further than just deprecating pkg_resources — it REMOVED
#      the module entirely. "pip install setuptools" with no version
#      cap therefore grabs the newest release and you'd hit the exact
#      same "No module named 'pkg_resources'" error again, just from a
#      different cause than problem #1.
# The upper bound below (<82) is what actually fixes this — it's not
# enough to just have "some" setuptools installed, it has to be one
# that still contains pkg_resources at all. (diarization.py's whole
# diarize() call is wrapped in a try/except that logs this and falls
# back to one default voice rather than crashing the cut if this pin
# is somehow bypassed — but you obviously want the real per-speaker
# voice feature working, not silently falling back to one voice.)
setuptools>=68.0.0,<82
